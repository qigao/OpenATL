# Hardware runner policy

Hardware HSP CI and its dedicated/self-hosted runner requirement were retired
by owner decision on 2026-10-31. No provisioning, runner label or GitHub Actions
workflow is required. Issue #15 is retired as not planned, not hardware-qualified.

Optional diagnostics run directly on a local Windows x64 host as described in
[CET_HARDWARE_ACCEPTANCE.md](CET_HARDWARE_ACCEPTANCE.md). They are outside CI and
are not prerequisites for merging or completing ATL/WTL functionality.
